The permutation flow job shop scheduling is a
popular optimization problem which is utilized in many
manufacturing facilities. Because of the permutations involved,
solving the problem was thought to be static, however, in several
practical cases, the problem is considered dynamic where the
job must schedule in a given number of machines in a cyclical
order. To minimize the makespan of the overall flow, several
algorithms were considered to solve this NP-hard problem and
recent approaches uses a few iterative and heuristic approach to
find ideal sequence of job schedule that minimize the overall
execution time of the machines. In this paper, the usage of
Greedy, Iterated Greedy, and Genetic Algorithms was used to
find the near optimal solution to minimize the total execution
time and maximize the utilization of the given number of
machines. The performance of the algorithm is tested and the
makespan calculated with this is compared with the benchmark
solution obtained from integer programming.
